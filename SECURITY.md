# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅ Active |

## Reporting a Vulnerability

If you discover a security vulnerability in TriDJs Stems Suite, please report
it privately by opening a security advisory on GitHub:

1. Go to https://github.com/[your-repo]/security/advisories
2. Click "New advisory"
3. Provide a detailed description of the vulnerability
4. Include steps to reproduce, affected versions, and potential impact

Please do **not** disclose vulnerabilities publicly until they have been
addressed by the maintainers.

## What to Expect

- You will receive an acknowledgment within 48 hours
- The maintainers will assess the severity and impact
- A fix will be prioritized based on severity
- You will be notified when the fix is released

## Best Practices

- Always use the latest release
- Only download the application from official sources
- Verify checksums when available
