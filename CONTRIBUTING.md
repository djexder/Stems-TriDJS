# Contributing to TriDJs Stems Suite

Thank you for your interest in contributing! This project is open-source and
welcomes contributions of all kinds — bug reports, feature requests, code
improvements, documentation, and more.

## How to Contribute

### Reporting Bugs

- Open an issue describing the problem
- Include steps to reproduce, expected behavior, and actual behavior
- Attach logs or screenshots if applicable

### Suggesting Features

- Open an issue with a clear description of the feature
- Explain why it would be useful and how it should work

### Pull Requests

1. Fork the repository
2. Create a branch with a descriptive name:
   - `fix/description` for bug fixes
   - `feat/description` for new features
3. Follow the existing code style
4. Test your changes locally before submitting
5. Open a pull request describing what was changed and why

## Development Setup

See [README.md](README.md) for build instructions. You'll need:

- Visual Studio 2022 with C++ desktop workload
- CMake ≥ 3.18

## Code Style

- Follow the conventions already present in the codebase
- Keep changes focused and minimal
- Avoid unnecessary reformatting

## Questions

Open an issue for any questions about contributing.
